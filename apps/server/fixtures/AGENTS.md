# Exploration fixtures

These are authored, synthetic course materials and conversations for local
product exploration. They are not customer data or externally sourced research.
`seed-exploration.ts` uses the real tenant and memory services to load them.
Keep a case inventory in `docs/memory-exploration.md`; do not turn it into a
scripted presentation or add canned runtime responses. Tests use temporary data.

`memory-upload.pdf` is an authored one-page ReportLab fixture (fixed metadata)
for exercising actual PDF.js extraction and exact-byte multipart downloads.
