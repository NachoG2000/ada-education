## Why

Ada needs an educational learning flow before automated memory: teacher-selected module content in shared channels, persistent artifacts in the existing right panel, and optional private tutor help with context. The current Inbox is a generic activity list and artifacts are not mounted.

## What Changes

- Channel-header Artifacts entry with count, list/detail navigation in the existing auxiliary panel and persistent preview cards for module guides.
- Teacher-authored guide, explanation, practice and assignment templates; private DM notes; persisted versions and personal work. Explicit submissions share a snapshot with teachers, never unpublished drafts.
- Ask privately selects an available course agent and creates a contextual editable draft, preserving artifact and return links without auto-sending.
- Actionable Inbox route with personal mentions/participated-thread replies, persistent read state and list/detail context navigation.
- No agent-generated application code, automatic memory extraction, mastery scoring, auto-grading, unsolicited tutor messages or altered DM visibility.
